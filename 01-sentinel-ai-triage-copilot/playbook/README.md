# Playbook export

`ai-triage-copilot.json` goes here — the exported Logic App workflow
definition.

**Security: the export contains the Gemini API key in the HTTP action's URI.
Before committing, replace the real key with the placeholder
`YOUR_GEMINI_API_KEY`. Never publish a real key.**

How to export it (Azure portal): open the Logic App `ai-triage-copilot` →
Automation → Export template → Download. Or open the designer → Code view →
copy the workflow definition.
